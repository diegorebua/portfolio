# Portfolio

## About
This is a portfolio web application designed to showcase projects, skills, and professional experience.

## Tech Stack
* React 18 + TypeScript
* Vite + CSS

## Getting Started

To get started with the project, follow these instructions:

1. Use Node.js 22 and enter the `frontend` directory.
2. Run `npm install`.
3. Run `npm run dev` and open the local address shown by Vite.
4. Run `npm run build` for a production build.
